# Online Learning and Student Performance Analysis

## Project Overview

This project analyzes online learning data to understand student performance, engagement, dropout, and pass rates using Power BI.

## Objectives

* Analyze student performance and engagement.
* Identify dropout and pass patterns.
* Compare students based on gender and region.
* Identify performance and risk levels.

## Tools Used

* Power BI
* Power Query
* DAX
* SQL

## Dataset

The dataset contains **32,885 student records** with information such as gender, region, education, total clicks, average score, engagement level, performance level, dropout flag, and pass flag.

## Dashboard

The Power BI dashboard includes KPIs and interactive visuals for:

* Total Students
* Dropout Rate
* Pass Rate
* Average Score
* Average Clicks
* Performance and Engagement Analysis

## Conclusion

The project converts online learning data into interactive visual insights that help understand student performance, engagement, and learning outcomes.
